# 블록 웹 편집기 (nocode-html-editor)

코딩을 몰라도 HTML 태그를 끌어다 놓아 웹페이지를 만들고, 그 결과를 HTML 코드로 바꿔 주는 웹 편집기입니다.

## 실행

요즘 브라우저(Chrome · Edge · Firefox · Safari)에서 쓸 수 있습니다. 내 컴퓨터 폴더를 직접 여는 기능만 Chrome · Edge 전용입니다.

```bash
python -m http.server 5530 --bind 127.0.0.1
```

그다음 브라우저에서 http://127.0.0.1:5530 을 엽니다.

## 화면 구성

| 탭 | 위치 | 하는 일 |
| --- | --- | --- |
| 탭1 프로젝트 | 왼쪽 | 브라우저 안 프로젝트(또는 내 컴퓨터 폴더) 열기, 페이지·폴더 만들기 / 열기 / 이름 바꾸기(F2) / 삭제(Del), zip 내보내기 · 가져오기 |
| 탭2 설정 (CSS) | 위 | 선택한 요소의 텍스트·모양·강조·배치·속성 바꾸기, 오른쪽에 **설정** · **코드로 변환** |
| 탭3 작업 공간 (HTML) | 가운데 | 요소를 놓고 옮기고, 두 번 클릭해서 글자 고치기. 위쪽 탭으로 여러 파일 열기 |
| 탭4 HTML 태그 | 아래 | 종류별 태그 모음. 클릭하면 넣기, 끌면 원하는 곳에 놓기 |
| 탭5 동작 (JS) | 오른쪽 | 블록을 끼워 맞춰 버튼·입력칸이 움직이게 만들기. 저장하면 `<script>` 로 들어감 |

탭 사이 경계선을 끌면 크기가 바뀌고, 두 번 클릭하면 접히거나 펴집니다.

### 프로젝트 (탭1)

- **브라우저 안 프로젝트** (기본): 페이지와 그림을 이 브라우저 저장소(IndexedDB)에 보관합니다. 설치나 폴더 권한 없이 어느 브라우저에서나 됩니다.
  - [새 프로젝트]: `index.html` 하나로 시작 · [예제]: 편집기와 함께 있는 예제 페이지로 프로젝트 만들기
  - 저장(Ctrl+S): 아직 파일이 아닌 새 페이지는 지금 프로젝트에 이름을 정해 저장 (열린 프로젝트가 없으면 최근 프로젝트, 그것도 없으면 「내 프로젝트」를 만듦)
  - 그림을 넣으면 프로젝트의 `images/` 폴더로 복사
- **프로젝트 메뉴** (탭1 위쪽 상자 버튼 또는 프로젝트 이름 클릭): 프로젝트 목록 · 새 프로젝트 · zip 으로 내보내기 · 가져오기 · 이름 바꾸기 · 삭제
  - zip 내보내기: 백업하거나 다른 컴퓨터로 옮기거나, 압축을 풀어 웹 서버에 그대로 올릴 수 있음
  - 가져오기: zip 은 새 프로젝트로, HTML · 그림 파일은 지금 프로젝트로 (그림은 `images/`)
- **내 컴퓨터 폴더** (Chrome · Edge): 예전처럼 실제 폴더를 열어 파일에 바로 저장
- 미리보기(새 창)에서도 프로젝트 안의 그림과 다른 페이지로 가는 링크가 동작합니다 (두 단계까지)
- 브라우저 저장소는 브라우저 데이터를 지우면 함께 지워질 수 있으니, 중요한 프로젝트는 zip 으로 내보내 두세요.

### 다른 곳에서 만든 HTML 가져오기

가져온 HTML 을 열면 편집기가 알아보고(편집기로 만든 파일에는 `<meta name="generator">` 표시가 있음) 다음처럼 바꿉니다.

- CSS 규칙(`#id`, `nav a`, `.a .b`, 태그 …)은 맞는 요소마다 스타일로 옮김 (우선순위 순서대로, `style=""` 이 마지막)
- `:hover` · `::after` · 640px 가 아닌 `@media` · `@keyframes` · `@import` · `*` 초기화 규칙처럼 옮길 수 없는 것은 「가져온 CSS」로 그대로 보존 (설정 → 페이지에서 보고 고칠 수 있음, 캔버스에도 적용)
- 링크 · 굵게 · 그림을 안에 담은 글자 요소(`<li><a>`, `<p>… <strong>`, `<a><img>`)는 상자로 바꿔 안의 요소를 살림. SVG 아이콘은 그대로 둠
- 같은 프로젝트의 CSS · JS 파일(`<link href="css/style.css">`, `<script src="js/app.js">`)은 페이지 안으로 읽어 들임 (CSS 안의 그림 주소도 고침)
- `<script>` 내용은 탭5 「코드」로, 외부 스크립트 · `<head>` 의 링크 · meta 는 그대로 보존
- 처음 저장할 때 원본을 `이름.원본.html` 로 남겨 둠

### 배치 방식

- 기본: 위에서 아래로 쌓임. 옆으로 놓으려면 「가로 배치」 상자 사용
- 「격자 배치」 상자 (또는 탭2 배치 → 격자): 표처럼 한 줄에 정한 칸 수만큼 차례로 채움
- 「자유 배치」 상자 (또는 탭2 배치 → 자유): 안의 요소를 마우스로 아무 위치에나 놓음. 화살표 키로 1px, Shift+화살표로 10px 이동
- 가로/세로 배치 안의 요소는 탭2 모양 → 「남은 공간 채우기」로 남은 자리를 모두 차지할 수 있음
- 탭3 위쪽 넓은 화면 버튼: 페이지를 실제 PC 화면처럼 1280px 폭으로 고정해서 봄

### 꾸미기

탭2 에서 글자 간격, 한쪽 테두리 (위/아래/왼쪽/오른쪽), 그라데이션, 배경 그림, 그림 맞추기, 넘침 숨기기, 그림자 색,
마우스 올리면 효과, 스크롤하면 나타나기, 위에 붙어 있기를 정할 수 있습니다.
글자 중 `*이렇게*` 별표로 감싼 부분은 「강조 글자색 · 강조 글꼴 · 강조 모양(기울임)」으로 보입니다 — 한 줄 안에서 글꼴 섞기 (예: `IDEAS WITH *visual impact.*`).

- **웹 글꼴**: 탭2 글꼴 목록의 「(웹)」 글꼴 (Noto Sans KR, 나눔, Inter, Anton, Instrument Serif, Geist …). 쓴 글꼴만 저장할 때 Google Fonts 링크로 자동으로 들어가고, 캔버스에서도 그 글꼴로 보입니다.
- **크기 단위**: 글자 크기 · 둥글게 · 여백 칸에 숫자만 쓰면 px, `2rem` · `5vw` · `50%` · `clamp(32px, 6vw, 96px)` 도 됩니다. 둥글게에 `8 8 0 0` 처럼 모서리를 따로.
- **세로 위치**: 위첨자 · 아래첨자 (탭4 텍스트의 「위첨자 `<sup>`」도 있음). 가로 배치의 「글자 기준선 맞춤」.
- **색 진하기**: 색 칸 옆 % 를 낮추면 반투명 (`rgba(…)`).
- **크기**: 최대 너비 · 최소 높이 · 가로세로 비율 (`16 / 9`).
- **띄워서 겹치기**: 이 요소만 띄워 다른 요소 위에 겹쳐 놓기 (자유 배치 상자가 아니어도). 「앞뒤 순서」(z-index) 로 겹치는 순서.
- **마우스 올림 스타일**: 탭2 맨 위 「기본 | 마우스 올림」에서 「마우스 올림」을 고르고 바꾸면 `:hover` 스타일이 됩니다 (캔버스에서도 마우스를 올리면 바뀜).
- **부품**: 탭4 입력 양식의 「스위치」(JS 없이 CSS `:checked` 로, 켜짐 · 꺼짐 색은 탭2 모양), 체크박스 · 라디오는 「체크 색」. 탭4 「아이콘」에 선 아이콘 40개 (글자색을 따라감, 탭2 속성에서 다른 아이콘으로 바꾸기).
- **설정 → 페이지**: 색 팔레트 (`이름: 색` — 코드에서 `:root { --이름 }` 과 `var(--이름)` 으로, 값을 바꾸면 쓰는 요소가 모두 바뀜, 「페이지에서 찾기」로 자동), 페이지 설명 · `<head>` 코드 (파비콘, og: 태그), 직접 쓰는 CSS.
- **탭3**: − / % / + 로 확대 · 축소 (Ctrl + 휠, % 를 누르면 폭에 맞추기 · 두 번 누르면 100%). 높이를 정한 빈 상자(선 · 원 · 색 견본)는 「끌어다 놓기」 칸으로 부풀지 않고 정한 크기로 보입니다.

- **움직임 · 효과**: 부드럽게 바뀌기(transition — 마우스 올림 스타일이 스르륵 바뀜), 회전, 흐리게, 뒤 배경 흐리게(유리 효과), 겹침 방식, 마우스 모양.
- **화면에 고정**: 「스크롤해도 붙어 있기」에서 화면 위 · 아래에 고정, 오른쪽 아래에 떠 있기.
- **부품** (탭4): 머리말 메뉴 · 첫 화면(히어로) · 카드 3칸 · 접는 내용(`<details>`) · 가로 넘기기(scroll-snap) · 팝업 창(`<dialog>`) · 떠 있는 버튼 — 모두 HTML + CSS 만으로.

### 코드 모양

- 스타일은 `<style data-wb>` 안의 클래스로 모입니다. 이름표(class)가 같은 요소끼리 스타일도 같으면 그 이름표를 그대로 클래스로 (`.switch`, `.notice-row`), 아니면 태그 종류 + 번호 (`.title_1`, `.row_3`).
- 직접 쓴 CSS · 가져온 CSS 는 따로 `<style>` 에 들어가서 다시 열어도 그대로입니다.

### 고른 요소 정보 · 눈금자

- 요소를 고르면 캔버스 선택 막대와 탭2 맨 위에 꼬리표가 보입니다: 노랑 `#id`, 초록 `.이름표`, 회색 `.c12`(코드로 변환하면 스타일이 들어가는 클래스). 탭2 꼬리표를 누르면 그 칸으로 갑니다.
- 탭3 위쪽 눈금자 버튼: 위 · 왼쪽 눈금자(px, 페이지 왼쪽 위가 0), 고른 요소 범위와 마우스 위치 표시.
  고른 요소 위에 바깥 여백(margin)은 주황, 안쪽 여백(padding)은 초록으로 칠하고 크기와 여백 숫자를 보여 줍니다.

### 태블릿 · 휴대폰 화면

탭3 위쪽 태블릿 · 휴대폰 버튼을 누르면 그 화면 보기가 되고, 이때 탭2 에서 바꾼 스타일은 그 화면에서만 적용됩니다
(코드에서는 태블릿 `@media (max-width: 1024px)`, 휴대폰 `@media (max-width: 640px)` 안으로. 태블릿 스타일은 휴대폰에도 이어짐). 예: 격자를 휴대폰에서만 1칸으로.

### 반복 · 공통 스타일

- 선택 막대의 「데이터로 반복」: 카드 하나를 틀로 표에 한 줄씩 적으면 카드가 만들어짐 (엑셀에서 붙여넣기 가능)
- **형식** (탭4 「형식 · 이름」 또는 탭2 맨 위 형식 고르기): 요소 하나의 모양을 형식으로 저장하고 다른 요소에 입히면, 그 뒤로는 하나만 고쳐도 모두 함께 바뀜
  - 함께 쓰는 것: 색 · 글자 · 테두리 · 여백 · 배치 (화면별 · 마우스 올림 스타일 포함). 따로인 것: 크기 · 위치
  - 코드에서는 `.형식이름 { … }` 규칙 하나로 나가고, 요소마다 다른 크기 · 위치만 따로 클래스로
  - 형식에서 떼기 · 이름 바꾸기 · 풀기, 가져온 페이지는 같은 클래스 · 같은 모양인 요소 묶음을 자동으로 형식으로
  - 「이름표」는 묶어 부르기만 하는 이름 (모양은 따로), 「요소 이름 (id)」 목록에서는 이름 바꾸기 · 지우기 (블록에서 쓰는 곳도 함께 바뀜)
- 탭4 「구조」: 페이지 요소를 나무 모양으로 보고 눌러서 고르기 (피그마의 레이어 목록처럼)
- 스타일 복사 · 붙여넣기: Ctrl+Shift+C / Ctrl+Shift+V

### 차트 · 표

탭4 「차트」에서 막대 · 선 · 영역 · 도넛 · 원 그래프를 넣고 값은 탭2 속성에 쉼표로 적습니다.
표를 고르면 탭2 속성에서 줄 · 칸 넣기 / 지우기, 제목 칸 바꾸기, 「크기…」(줄 수 × 칸 수, A·B·C 제목 줄과 1·2·3 번호 칸)를 할 수 있습니다.
「표 계산」을 켜면 칸에 `=A1+B1`, `=SUM(A1:A9)`, `AVERAGE` · `MIN` · `MAX` · `COUNT` 를 쓸 수 있고, 캔버스와 저장한 페이지에서 계산된 값이 보입니다.

### 보는 사람이 직접 만지기

- 글자 요소: 탭2 속성 「보는 사람이 글자를 고칠 수 있게」 (스프레드시트 칸 등)
- 탭2 강조 · 움직임: 「보는 사람이 끌어서 옮기기」(가로로만 / 세로로만 / 아무 방향), 「양 끝을 끌어 길이 조절」 (영상 클립처럼)
- 「스크롤해도 붙어 있기」: 위에 붙기 / 왼쪽에 붙기 (표의 제목 줄 · 번호 칸)
- 크기 「화면」: 브라우저 화면 높이(너비)만큼 — 편집 프로그램처럼 한 화면을 꽉 채울 때

### 예제

- `examples/portal/` — 가상 포털 "모아"의 첫 화면 + 로그인 화면 (로그인 버튼은 블록으로 이동)
- `examples/practice-sites/` — 쇼핑몰 상품 목록 · 관리자 대시보드 · 개인 포트폴리오
  - shop: 이름표로 분류 필터 · 평점/리뷰/할인/가격 정렬, 휴대폰에서 2칸
  - dashboard: 선 · 도넛 · 막대 · 영역 차트, 메뉴 하나만 켜기, 휴대폰에서 1칸
  - portfolio: 스크롤하면 나타나기, 위에 붙는 메뉴, `*강조*` 이름, 하트 ♡ ↔ ♥, 휴대폰 화면
  - sheet: 스프레드시트 (12열 × 50행, 칸 바로 고치기, `=A2+B2` · `=SUM` · `=AVERAGE` 수식, 엔터/화살표 이동, 수식 줄, 굵게·기울임·밑줄·색칠, 행·열 넣기/지우기, 제목 줄·번호 칸 고정)
  - offcut: 디자인 스튜디오 소개 보드 (웹 글꼴 Anton · Instrument Serif · Geist, 겹친 카드, 큰 글자 배치 — HTML · CSS 중심)
  - settings: 설정 대시보드 (사이드바 · 알림 스위치. 스위치는 JS 없이 HTML + CSS `:checked` 로)
  - video-editor: 영상 편집 (화면 꽉 채움, 클립 끌어 옮기기 · 양 끝으로 길이 조절, D 복제 · Delete 지우기, 재생/스페이스, `01:00:초:프레임` 시간, 확대 · 회전 · 위치 · 투명도, 재생 중 소리 막대)

### 동작 블록 (탭5)

왼쪽 분류(이벤트 · 흐름 · 화면 · 움직임 · 소리 · 조건 · 계산·글자 · 데이터 · 함수 · 고급)에서 블록을 골라 작업판으로 끌어옵니다.
「…했을 때」 이벤트 블록 아래에 할 일을 붙이고, 둥근 값 블록과 각진 조건 블록(?)은 칸에 끼웁니다.

- 블록 찾기(모든 분류에서), 목록에서 두 번 클릭하면 고른 블록 아래에 추가, 블록을 클릭한 뒤 Delete 로 지우기 · Ctrl+D 로 복제
- 캔버스에서 요소를 고른 채 블록을 꺼내면 그 요소가 미리 들어가고, 요소 칸의 「🎯 캔버스에서 클릭해서 고르기」로도 고를 수 있음
- 이벤트: 두 번 클릭 · 마우스 올림/벗어남 · 값 바뀜 · 입력 시작/끝 · 오른쪽 클릭, ~초마다, 스크롤했을 때
- 목록(배열): 추가 · 지우기 · 비우기 · ~번째 항목 · 항목 수 · 항목마다 반복 · 이어 붙이기
- 함수: 값을 넘겨받고 결과를 돌려주는 블록 묶음
- 저장(브라우저에 남김) · 자료 받아오기(fetch + JSON) · 속성 읽기/쓰기 · 이름표(형식) 붙이기/떼기 · 팝업 열기
- 글자 수 · 일부 · 바꾸기 · 들어 있는가, 반올림 · 쉼표 숫자, 날짜 · 시각, 마우스 위치 · 스크롤 거리 · 화면 크기
- 고급: 「JS 실행」 · 「JS 값」 블록으로 JavaScript 한 줄을 블록 사이에 넣기, 기록 남기기, 시도하기/오류가 나면
「자료」에서 변수, 「시작」에서 신호를 만들 수 있고, ▶ 시작하기 를 누르면 새 창에서 실행해 볼 수 있습니다.
블록에서 요소를 고르면 그 요소에 id 가 자동으로 붙습니다 (예: `button1`). 블록 모양은 HTML 안에 `wb-blocks` 로 함께 저장되어 다시 열면 되살아납니다.

탭5 위쪽 「블록 | 코드」에서 「코드」를 고르면 JavaScript 를 직접 쓸 수 있습니다. 블록과 함께 실행되고
`el('id')`, `on('id', 'click', fn)`, `vars['변수']` 를 쓸 수 있습니다. 문법 오류는 바로 아래에 빨갛게 보이며,
저장할 때는 블록 코드와 다른 `<script>` 에 넣어서 직접 쓴 코드에 실수가 있어도 블록은 그대로 돌아갑니다.

요소가 많아도 블록을 빠르게 쓸 수 있게 만든 기능:

- 「이름표 ~ 요소를 클릭했을 / 고쳤을 / 끌어서 놓았을 때」: 칸 300개, 클립 20개에도 블록 묶음 하나
- 요소 칸의 「⟐ 이 요소」(방금 누르거나 바뀐 요소) · 「⟐ 고른 요소」 · 「⟐ 방금 복제한 요소」
- 「고른 요소로 정하기」(파란 테두리) · 「고른 요소를 위/아래/왼쪽/오른쪽 옆으로 옮기기」 (표에서는 칸 이동)
- 「~의 너비/높이/굵기/테두리… 정하기」, 「~ ↔ ~ 번갈아 바꾸기」, 「각도를 ~도로 정하기」, 「크기 배율 ~%」
- 「복제해서 넣기」 · 「지우기」 · 「~ 칸 기준으로 표에 줄/칸 넣기·지우기」 (제목 줄 · 번호 칸은 다시 매김)
- 계산: 나누기 나머지 · 몫, 「~ 자리로 맞추기」 (시간 표시 `01:00:09:04`)
- 자료: 「표 칸 주소 (A1)」, 「수식」, 「칸에 ~ 쓰기」
- 키 블록: 「글자 입력 중이 아닐 때만」(기본) / 「언제나」

## 파일 구조

- `index.html` — 화면 뼈대
- `css/app.css` — 편집기 화면 스타일 (어둡게/밝게 테마)
- `js/core.js` — 문서 모델, 실행 취소, 공용 도구
- `js/effects.js` — 마우스 올리면 · 나타나기 효과, 글자 강조, 차트 그리기, 표 계산, 끌어서 옮기기 (캔버스와 코드 변환이 함께 씀)
- `js/repeater.js` — 데이터로 반복해서 만들기
- `js/blockcode.js` — 블록 종류 정의, 블록 → JavaScript 변환
- `js/codegen.js` — 문서 ↔ HTML 코드 변환
- `js/palette.js` — 탭4 태그 모음
- `js/canvas.js` — 탭3 캔버스 (Shadow DOM 안에 페이지를 그림)
- `js/inspector.js` — 탭2 스타일 설정
- `js/formats.js` — 탭4 「형식 · 이름」 · 「구조」 보기
- `js/vfs.js` — 브라우저 안 프로젝트 저장소 (IndexedDB, 폴더 핸들과 같은 모양) · zip 만들기 · 읽기
- `js/explorer.js` — 탭1 프로젝트 (브라우저 프로젝트 · 내 컴퓨터 폴더)
- `js/blocks.js` — 탭5 블록 코딩 화면 (끌어서 끼우기)
- `js/app.js` — 탭 크기 조절, 문서 탭, 저장, 설정, 단축키
